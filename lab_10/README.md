# Крестики-нолики

Игра «Крестики-нолики» с графическим интерфейсом на tkinter.

## Файлы

- main.py — код игры
- img/x.png — иконка игрока (опционально)
- img/o.png — иконка AI (опционально)
- docs/ — тестовая документация

## Установка

### Создайте виртуальное окружение:

```bash
python -m venv venv
```

### Активируйте его:

```bash
source venv/Scripts/activate
```

### Установите зависимости:

```bash
pip install -r requirements.txt
```

## Картинки

Положите в папку img файлы x.png и o.png.
Если файлов нет — игра покажет буквы X и O.

## Запуск

```bash
python main.py
```
